# libgdx 游戏引擎编辑器（结绳 IDE 插件）

在**代码编辑器的长按菜单**（扩展点 `domain.menu.editor.code` / `domain.menu.editor.text`，右上角菜单用 `domain.menu`）里
加一项「**游戏引擎编辑器**」：点开就是可视化场景编辑器，拖组件、调属性，一键把对应的 libgdx 结绳代码插到光标处。

- 插件包：`libgdx游戏引擎编辑器-1.0.rmx`（≈21 KB）
- 插件 ID：`com.dsh.libgdxeditor`
- 依赖：宿主已经带的 `studio-api`（插件里用 `compileOnly`，不打包）；生成的代码依赖绳包 **libgdx中文游戏引擎6.5**

## 安装

三选一：

1. 直接把 `.rmx` 和 `program.json` 放进宿主工作区（本机就是 `/sdcard/Tiecode/Programs/com.dsh.libgdxeditor/`），重启 IDE：

   ```
   /sdcard/Tiecode/Programs/com.dsh.libgdxeditor/libgdx游戏引擎编辑器-1.0.rmx
   /sdcard/Tiecode/Programs/com.dsh.libgdxeditor/program.json
   ```

2. 把 `.rmx` 拷到 `/sdcard/Tiecode/`，在 IDE 里用「安装程序/插件」选它安装。
3. 在 IDE 的插件管理里直接选文件安装。

入口一共挂了四处（都叫「游戏引擎编辑器」）：**代码区长按**（`domain.menu.editor.code` / `.text`）、
**工程右上角菜单**（`domain.menu`）、**工程文件树里对文件长按/右键**（`project.menu.file`）。

装完**一定重启一次 IDE**（插件是启动时扫描 `Programs/` 加载的），然后打开任意 `.t` 文件 →
在代码区**长按** → 菜单里就有「**游戏引擎编辑器**」。

> **最大的坑（已踩）：`program.json` 里的 `minSupport` 必须写 `2`。**
> 书契/结绳 R2 的 `ProgramVersion.MIN_COMPATIBLE = 2`，写 `1` 会被宿主判定成
> "Plugin requires unsupported old platform version"，然后
> `disableUnsupportedPrograms()` 往你的 program.json 里**写一行 `"enabled": false`**，
> 而 `ProgramManagerImpl.activateAllPrograms()` 会 `if (!wrapper.isEnabled()) continue;`
> —— 插件照常出现在「插件」页里，但**扩展点一个都不会注册**，菜单里自然没有。
> （对照：IDE 自带的 `Javac8.rmx` 就是 `"minSupport": 2`。）

> **第二个坑（已踩）：`program.json` 必须写 `"file": "你的.rmx 文件名"`。**
> 宿主加载程序时用的是 `new ZipFile(<程序目录> + "/" + model.file)`；
> 缺这个字段时路径变成 `…/com.dsh.libgdxeditor/null`，抛
> `java.nio.file.NoSuchFileException`，表现成插件对话框里的
> "Extension point 'domain.menu.editor.code' activate failed: Instance class '…GameEditorMenu' failed"。
> （对照：你用结绳装出来的 `/sdcard/Tiecode/Programs/com.dsh.nomount/program.json` 里就有
> `"file":"结绳免安装插件-4.7.0(1).rmx"`。）

> 次要记录：菜单类**不要**覆写 `getParentId()` / `getAnchor()`。
> `studio-api` 里这两个方法只是编不过的桩（`UnsupportedOperationException`），真正的默认值由宿主提供；
> 我第一版按 `MenuAction.ID_ROOT` 写死，结果插件能装、能在「插件」页看到，但长按菜单里**不显示**。
> 改成照官方样例（`Product-Plugin/Java/.../DesignerEditorMenuAction`，只覆写 `perform/getId/getTitle/getIcon`）
> 之后就正常了。

## 用法

1. 长按代码 → 「游戏引擎编辑器」→ 打开**结绳本体同款的插件页面**（`SimplePluginPage` + `LayoutDesignerView`），
   不是自绘弹窗，也不是 Dialog。
2. 界面就是结绳「设计布局」那一套，**左右抽屉铺满屏幕**：
   - 左侧红按钮 **编辑** → 左抽屉：**组件栏**（添加组件 / 添加布局组件）、**布局结构**（元素树）、
     下面的**操作条**：`插入代码 | 复制代码 | 上移 | 下移 | 复制 | 删除`
   - 右侧红按钮 **属性** → 右抽屉：当前选中组件的**属性表**（名称 / 文本 / 贴图 / X / Y / 宽 / 高 / 旋转）
   - **返回键先关抽屉**，抽屉都关了再按一次才退出编辑器
3. 属性怎么改：
   - 名称 / 文本 / X / Y / 宽 / 高 / 旋转 → 结绳自带的底部输入弹窗（`QiBottomTextInputDialog`），数字按小数解析
   - **贴图 → 直接列工程 `assets/` 里的资源**（png 直接选；`.atlas` 展开成一个个区域，
     存成 `ui/items.atlas#background` 这种形式），不用手打路径
4. 中间画布就是舞台本身（按内容区等比缩放、居中；网格每 40 个世界单位一格）：
   - **单指拖动** = 移动元素，**拖右下角黄点** = 改大小，**拖顶部黄点** = 旋转
   - **点元素** = 选中（结构树同步高亮），**点空白** = 回到舞台属性
   - 坐标就是 libgdx 的世界坐标：**左下角是原点，Y 向上**
5. 操作条：`插入代码` 把生成的结绳代码合并进当前文件并退出编辑器；`复制代码` 进剪贴板；
   `上移 / 下移` 调层级顺序；`复制` 克隆一个（自动起不重名的名字）；`删除` 删掉选中的组件。

## 生成的代码长这样

```结绳
类 我的游戏场景
	变量 舞台:舞台?
	变量 皮肤:场景皮肤?
	变量 标题:标签?
	变量 篮球:精灵?
	变量 道具组:组?

	方法 创建场景()
		舞台=创建 舞台
		皮肤=创建 场景皮肤
		标题=标签.创建标签("小鸡顶篮球", 皮肤)
		标题.置位置(60, 600)
		标题.置大小(160, 48)
		舞台.添加控件(标题)
		篮球=创建 精灵
		// TODO 精灵要用图集区域：篮球.置区域(纹理图集.创建纹理图集("你的图集.atlas").取区域("区域名"))
		篮球.置位置(350, 500)
		篮球.置大小(64, 64)
		道具组=创建 组
		道具组.置位置(20, 20)
		道具组.置大小(200, 200)
		舞台.添加控件(道具组)
	结束 方法

	方法 绘制场景(画布:纹理画布)
		舞台.动作响应(操作类.取时间())
		画布.开始绘制()
		舞台.绘制()
		篮球.绘制(画布)
		画布.结束绘制()
	结束 方法

	方法 触摸(屏幕X:整数, 屏幕Y:整数, 按下:逻辑型)
		如果 按下 则
			舞台.触摸按下(屏幕X, 屏幕Y, 0, 0)
		否则
			舞台.触摸抬起(屏幕X, 屏幕Y, 0, 0)
		结束 如果
	结束 方法
结束 类
```

生成结果**已经用结绳编译器实测编译通过**（`tiec` 0 错误），不需要外部贴图/皮肤就能过编译；
想显示真正的图片/精灵时，按代码里的 `TODO` 填一行 `置纹理` / `置区域` 即可。

## 为它给绳包补的东西（都已在 libgdx中文游戏引擎6.5.tlb 里）

- `图片 / 标签 / 文本按钮 / 表格`：补上「演员」通用操作（`置位置 / 置大小 / 旋转 / 可见 / 置缩放 / 置颜色 / 添加动作 / 取名称 / 取舞台` 等）
- 新增 `组`（对应 scene2d `Group`：`添加演员 / 移除演员 / 清空演员 / 取演员数量 / 取演员`）
- `舞台`：补 `添加控件(对象)`（标签/图片/按钮/表格/组都不是结绳的「演员」子类，必须走这个口）、
  `触摸按下 / 触摸抬起 / 触摸拖动 / 滚动 / 按键按下 / 按键抬起`
- `表格`：补 `添加控件(对象)`

## 画布/编辑器能力（当前版本）

- 组件栏：演员 / 图片 / 标签 / 文本按钮 / 表格 / 组 / 精灵
- 拖动：单指移动、右下角圆点缩放、顶部圆点旋转、长按出 复制/删除/置顶/置底
- 属性：名称 / 文本 / **贴图** / X / Y / 宽 / 高 / 旋转；「选择文件」调系统文件选择器挑贴图
- **画布直接显示贴图**（路径相对当前 .t 文件或它的 assets/ 解析），没有贴图才画色块
- **撤销 / 重做**（30 步快照）
- **打开时自动从当前代码读回场景**：代码里已有 `变量 X:图片?` + `X.置位置(…)` 这类内容会变成画布上的元素，接着改就行
- 保存场景到 `<文件>.scene.json`；「插入代码」把生成结果塞到光标处

## 自检日志（判断插件有没有被宿主加载）

插件会往 `/sdcard/Tiecode/libgdx游戏引擎编辑器.log` 写几行关键事件：

```
GameEditorMenu 已实例化（宿主在注册/构建「代码操作」菜单）   ← 说明宿主认了这个扩展点
perform() 被调用：菜单项「游戏引擎编辑器」被点击            ← 说明菜单项能点
插入代码：1234 字符                                        ← 说明代码插进了编辑器
```

装完插件执行一次长按，如果这个文件都没生成，说明宿主没有实例化插件类（扩展点没生效）；
如果生成了「已实例化」但菜单里看不到，就是菜单层被过滤了。

## 自己编译

```bash
cd libgdx游戏编辑器插件
bash tools/build-rmx.sh     # javac + D8 + aapt2 + zipalign，产出 libgdx游戏引擎编辑器-1.0.rmx
```

（脚本参考 dsh 下「结绳安卓工程aar构建插件」的 `tools/build-rmx.sh`，不需要 Gradle / Android SDK。）

## 已知限制

- 皮肤是空皮肤 `创建 场景皮肤`：标签/按钮能显示，但没样式；想要好看的样式把 `TODO` 那行换成 `皮肤.创建皮肤("uiskin.json")`。
- 精灵不进舞台，是每帧直接 `绘制(画布)` 的（libgdx 的 Sprite 本来就不属于 scene2d）。
- 画布只画方块示意，不渲染真实贴图（要贴图得先让插件知道资源路径，后续可以再加）。
